Partie 1 :

  1. Peut-on penser que l’âge est différent selon le statut PUPD ?

Il s’agit de faire le lien entre une variable qualitative (PUPD) et une variable quantitative (âge). On va utiliser un test de comparaison de moyennes. On teste \(H_0:\mu_{PUPD=0}=\mu_{PUPD=1}\) par un test de Student :

t.test(Age~PUPD,data=Hirsutisme2)

    Welch Two Sample t-test

data:  Age by PUPD
t = 0.69151, df = 65.726, p-value = 0.4917
alternative hypothesis: true difference in means between group N and group O is not equal to 0
95 percent confidence interval:
 -1.602222  3.299952
sample estimates:
mean in group N mean in group O 
       21.14516        20.29630 
ggplot(Hirsutisme2,aes(x=PUPD,y=Age))+
  geom_boxplot()+
  geom_jitter(width=.1,col="pink")+
  theme_bw()

Au risque de 5% on ne peut pas rejeter H0, c’est à dire que l’on ne peut pas affirmer qu’il existe une différence significative au niveau de l’âge selon le statut PUPD.

  1. Peut-on penser que plus la cortisol est élevée et plus l’insulinémie l’est également ?

Les deux variables considérées sont quantitatives, on fait donc un test de corrélation ou bien un test sur la pente du modèle :

mod <- lm(cortisol ~ insulinemie, data = Hirsutisme2)
summary(mod)

             abs(round(beta1, 2)), " x   (R² = ", round(r2, 3), ")")

ggplot(Hirsutisme2, aes(x = insulinemie, y = cortisol)) +
  geom_point() +
  geom_smooth(method = "lm") +
  annotate("text", x = -Inf, y = Inf, label = eq,
           hjust = -0.1, vjust = 1.5, size = 8) +
  theme_bw()
`geom_smooth()` using formula = 'y ~ x'

Au risque de 5%, on ne peut pas affirmer qu’il existe un lien significatif entre le cortisol et l’insulinémie (\(p-value=0.054\)). Rappel la \(p-value\) doit être significativement inférieure au risque !

  1. Peut-on penser que les boiteries sont plus présentes chez les individus hirsutes ?

Les deux variables considérées sont qualitatives donc on va faire un test du chi2

obs<-table(Hirsutisme2$diagnostic,Hirsutisme2$boiterie)
chisq.test(obs)

    Pearson's Chi-squared test with Yates' continuity correction

data:  obs
X-squared = 0.60995, df = 1, p-value = 0.4348
tab <- Hirsutisme2 %>%
  filter(!is.na(diagnostic), !is.na(boiterie)) %>%
  count(diagnostic, boiterie) %>%
  group_by(diagnostic) %>%
  mutate(
    pct   = n / sum(n),
    label = paste0("n = ", n, "\n",
                   percent(pct, accuracy = 0.1, decimal.mark = ","))
  ) %>%
  ungroup()

ggplot(tab, aes(x = diagnostic, y = n, fill = boiterie)) +
  geom_col(position = "fill") +
  geom_text(aes(label = label),
            position = position_fill(vjust = 0.5),
            size = 3.5, color = "white", fontface = "bold") +
  labs(title = "",
       x = "diagnostic",
       y = "Pourcentage") +
  scale_y_continuous(labels = scales::percent) +
  theme_bw()

Donc au risque de 5%, on ne peut pas affirmer qu’il existe un lien entre le diagnostic et la présence de boiterie (\(p-value=0.4348\)).
